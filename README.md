# 올패스 티칭

수업 지도안부터 세특까지, 교사가 실제로 쓰는 문서를 한 자리에서 만드는 웹 도구입니다.

초·중·일반고 교사를 위해 만들었습니다. 수업에서 다룰 내용을 적으면 2022 개정 교육과정 성취기준을 찾아 연결합니다. 거기서부터 지도안·학습지·수행평가·채점·세특까지 이어집니다. 단계마다 나오는 결과물은 한글(HWPX)·워드(DOCX)·PDF로 바로 내려받아 학교 양식에 넣을 수 있습니다.

AI는 초안만 만듭니다. 점수를 확정하거나 기록을 완성하는 건 언제나 교사입니다.

## 다섯 단계

| 단계 | 하는 일 | 내려받기 |
| --- | --- | --- |
| 01 지도안 | 성취기준 연결, 수업 모형 선택, 약안·세안 작성 | HWPX · DOCX · PDF |
| 02 학습지 | 지도안 흐름에 맞춘 문항과 응답 공간, 교사용 답안 | PDF · HWPX |
| 03 수행평가 | 수행과제와 분석적 루브릭, 학생 안내문 | PDF · HWPX · DOCX · XLSX |
| 04 OCR·채점 | 답안 PDF에서 글자 추출, 루브릭 수준별 채점 | — |
| 05 세특 | 채점 근거를 이어받은 과목별 세부능력 특기사항 | — |

앞 단계 결과가 뒤 단계 입력이 됩니다. 앞 단계를 고치면 뒤 단계에 `검토·재생성 필요` 표시가 붙습니다. 기존 문서가 지워지지는 않습니다.

## 이런 점을 신경 썼습니다

**교사 판단을 대체하지 않습니다.** AI가 만든 것은 승인 전까지 `AI 초안`으로 표시됩니다. 그림·수식·그래프 답안이나 인식이 불확실한 부분은 자동 채점에서 제외하고 `교사 확인 필요`로 남습니다. 원본을 확인하고 수준을 고르기 전에는 총점이 확정되지 않습니다.

**학생 자료를 쌓아두지 않습니다.** 답안 PDF는 글자 추출을 위해 Upstage로 보내며 원본은 보관하지 않습니다. 학생 이름과 추출 텍스트, 채점 결과는 현재 탭에만 저장되고 탭을 닫으면 사라집니다. `학생 자료 모두 지우기`는 어느 단계에서든 누를 수 있습니다.

**수업에 쓸 도구를 검색해서 반영합니다.** 스노클이나 패들렛처럼 실제로 쓸 AI·에듀테크 도구를 적으면 검색으로 기능을 확인한 뒤 지도안과 학습지에 넣습니다. 확인되지 않으면 `미검증 도구`로 표시해 지어낸 기능이 문서에 들어가지 않게 합니다. 반대로 수업 내용에 맞는 도구를 추천받을 수도 있습니다.

**한글 문서를 제대로 만듭니다.** HWPX는 구조 검증기를 통과한 파일로 만듭니다. 표 안 긴 내용은 페이지를 넘겨 이어지고 잘리지 않습니다.

## 시작하기

Node.js 20 이상이 필요합니다.

```bash
npm install
cp .env.example .env    # 키를 채워 넣습니다
npm run dev             # http://localhost:3000
```

환경변수는 이렇게 씁니다.

| 이름 | 필수 | 쓰임 |
| --- | --- | --- |
| `UPSTAGE_API_KEY` | 필수 | 문서 생성과 OCR |
| `GRADING_INTEGRITY_SECRET` | 필수 | 채점 결과 위변조 방지. 32자 이상이어야 채점 단계가 열립니다 |
| `TAVILY_API_KEY` | 선택 | 수업 도구 검색. 없으면 키가 필요 없는 검색으로 대체합니다 |

배포용 빌드는 `npm run build`입니다. 교육과정 데이터를 먼저 만든 뒤 빌드합니다.

## 테스트

```bash
npm test          # 단위·통합 테스트
npm run test:e2e  # 브라우저 시나리오
```

내보내기 테스트는 만들어진 PDF와 엑셀을 실제로 열어봅니다. HWPX·DOCX는 압축을 풀어 구조를 확인합니다. 테스트는 학생 답안 파일을 남기지 않습니다.
