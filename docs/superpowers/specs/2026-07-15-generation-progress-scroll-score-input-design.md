# AI 진행률·맨 위로·점수 입력 개선 설계

## 목표

AI 생성 중 예상 진행률을 퍼센트로 보여주고, 다섯 프로세스마다 상단 복귀 동작을 제공하며, 루브릭 점수 입력 중 `0`이 강제로 되살아나는 불편을 없앤다.

## 설계

- Upstage가 토큰 단위 진행률을 제공하지 않으므로 단일 AI 작업은 세션의 예상 소요 시간과 경과 시간을 이용한 `예상 진행률`을 표시한다. 진행률은 대기 중 95%를 넘지 않고 작업 완료 시에만 100%가 된다. 학생별 일괄 작업은 기존 실제 완료 비율을 유지한다.
- `TeachingWorkflow`가 모든 프로세스 패널의 공통 상단 기준점을 소유한다. 각 프로세스 콘텐츠 하단의 `맨 위로` 버튼은 이 기준점으로 이동하며 키보드 포커스도 프로세스 내비게이션으로 돌려보낸다.
- 루브릭 수준별 점수는 문자열 초안으로 편집하고, 빈 값은 입력 중 그대로 유지한다. blur 또는 Enter에서만 정수로 반영하며 Escape는 기존 값으로 복원한다. 포커스할 때 기존 숫자를 전체 선택해 모바일과 데스크톱 모두 덮어쓰기가 쉽도록 한다.

## 접근성 및 오류 처리

- 진행률은 `progressbar`의 `aria-valuenow`와 화면의 `%` 텍스트를 함께 갱신하고 `예상 진행률`이라고 명시한다.
- `맨 위로`는 실제 `button`이며 스크롤 뒤 프로세스 내비게이션에 포커스를 둔다.
- 빈 점수나 범위를 벗어난 값은 기존 점수를 유지하고 해당 입력에 다시 포커스를 둔다. 유효한 0점은 허용한다.

## 검증

- operation-state 단위 테스트로 시간 기반 예상 진행률의 단조 증가와 95% 상한을 검증한다.
- 컴포넌트 테스트로 AI 대기 오버레이의 퍼센트, 다섯 프로세스의 상단 복귀, 빈 점수 편집 후 유효 값 반영을 검증한다.
- 전체 Vitest, 프로덕션 빌드, Playwright 데스크톱·모바일에서 시각 및 키보드 동작을 확인한다.
