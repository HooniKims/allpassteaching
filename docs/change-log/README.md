# 수정 요청·개선 기록 운영 규칙

교사가 요청한 수정 사항과 실제 반영 결과를 날짜별로 남긴다. 나중에 “무엇을 왜 바꿨는지”를 빠르게 찾는 것이 목적이다.

## 경로와 시각

- 날짜 파일: `docs/change-log/YYYY/MM/YYYY-MM-DD.md`
- 모든 항목은 작업 당시 한국 표준시를 `HH:MM KST` 형식으로 기록한다.
- 같은 시각에 받은 묶음 요청은 종류별 제목 아래 나누되, 원래 요청 번호를 유지한다.

## 종류

1. 화면·사용성
2. 생성·AI
3. 교육과정·데이터
4. 문서 내보내기
5. 버그 수정
6. 테스트·검증

## 항목 필드

- 요청: 교사가 원하는 결과
- 상태: 대기 / 진행 중 / 구현 완료 / 검증 완료 / 보류
- 반영: 사용자 관점에서 달라진 동작
- 파일: 주요 변경 파일
- 검증: 자동 테스트나 수동 확인 결과
- 제약: 아직 확인하지 못한 환경 또는 후속 판단

새 요청은 기존 문장을 덮어쓰지 않고 같은 날짜 파일에 새 시각 항목으로 추가한다. 구현 상태나 검증 결과가 바뀌면 원래 항목의 상태·검증·제약을 갱신한다.
