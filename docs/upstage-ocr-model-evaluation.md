# Upstage OCR 모델 선택 기록

## 목표

학생이 제출한 수행평가 PDF에서 채점 근거로 쓸 본문을 추출한다. 단순 문자 인식뿐 아니라 문서의 읽기 순서와 구조를 최대한 보존하고, 교사가 추출 결과를 수정한 뒤 채점할 수 있어야 한다.

## 후보 비교

| 후보 | 강점 | MVP 판단 |
| --- | --- | --- |
| Document OCR | 문자 추출에 집중하며 페이지당 비용이 낮다. | 단순 본문 추출에는 유리하지만 표·문단 구조가 중요한 수행평가에는 추가 후처리가 필요하다. |
| Document Parse | PDF·스캔 문서의 텍스트와 레이아웃을 구조화하며 OCR 강제 옵션을 제공한다. | 채점 근거의 읽기 순서와 문서 구조를 함께 확보할 수 있어 현재 워크플로우에 더 적합하다. |

공식 콘솔 예제의 `document-parse` 모델과 `ocr=force` 조합을 사용한다. 가격과 기능은 [Upstage API 가격](https://www.upstage.ai/pricing/api), API 형식은 [Document Parse 콘솔 예제](https://console.upstage.ai/api-keys?api=document-parsing), 제품 범위는 [Document Parse 소개](https://www.upstage.ai/products/document-parse?category=Company)를 기준으로 2026-07-11에 확인했다.

## 적용값

- 엔드포인트: `https://api.upstage.ai/v1/document-digitization`
- 모델: `document-parse`
- OCR 모드: `force`
- 입력 제한: PDF만, 파일당 10MB, 한 번에 최대 10개
- 처리 방식: 동시 2개, 학생별 부분 실패와 개별 재시도 허용
- 보존 정책: 원본 PDF는 브라우저 저장소에 저장하지 않고 현재 처리 중에만 사용한다. 추출 텍스트는 교사가 확인·수정할 수 있다.

## 실제 연결 시험

2026-07-12 KST에 생성된 2페이지 한국어 PDF로 실제 API 스모크 테스트를 수행했다.

- 결과: 통과
- 응답 모델: `document-parse`
- 처리 시간: 3,399ms
- 페이지 수: 2
- 추출 텍스트 길이: 142자
- 확인 문구 일치: 성공

API 키와 원문 응답은 로그에 출력하지 않았다. 이 시험은 API 연결, 다중 페이지 처리, 텍스트 반환 계약을 확인한 것이며 실제 학생 필기체 정확도를 의미하지 않는다.

### 2026-07-13 비식별 멀티모달 계약 재시험

학생 데이터가 전혀 없는 1쪽 합성 PDF에 영문 확인 문구, `x^2 = 4` 수식, 선 그래프를 넣어 Standard 계약을 다시 호출했다.

- Standard: 통과, `document-parse`, 3,365ms, 1쪽, 142자, 요소 4개
- 요소 범주: chart 1, heading1 1, paragraph 2
- 좌표가 있는 요소: 4개
- 확인 문구: 일치
- 핵심 수식 기호: 이번 합성 자료에서는 일치했지만 결과 상태는 `teacher_review`로 유지
- Enhanced: 환경에 모델이 설정되지 않아 호출하지 않음

스모크 출력은 모델·시간·쪽수·문자 수·요소 수·범주·안전 상태만 담는다. API 키, 원문, OCR 전체 응답, 사람 이름은 출력하지 않는다. Enhanced가 설정된 환경에서만 같은 합성 자료로 별도 호출하며, 실패 시 Standard 결과를 자동채점에 승격하지 않는다.

## 정확도 검증 상태와 한계

실제 비식별 한국 학생 손글씨, 수학 풀이, 과학 그래프·도표, 학생 그림 표본은 제공되지 않았다. 따라서 실제 학생 자료의 문자·수식·시각 의미 정확도 검증은 외부 표본 부재로 수행할 수 없으며, 현재 결과를 정확도 검증 완료로 표현하지 않는다.

소프트웨어 안전장치는 동작한다. 수식·차트·그림, 낮은 신뢰도, 잘린 요소, 좌표가 없거나 잘못된 요소는 점수를 만들지 않고 `교사 확인 필요`로 보낸다. 수식의 모든 핵심 기호가 일치하더라도 교사는 원본 위치와 판독 문자열을 대조한 뒤 현재 루브릭의 허용 수준을 직접 선택해야 한다.

## 다음 품질 시험

실제 적용 전에는 개인정보를 제거한 대표 표본으로 인쇄체·필기체·수식·표·과학 도표·학생 그림을 나누어 문자 정확도, 핵심 기호 보존, 의미 보존, 읽기 순서, 표 구조, 페이지당 비용, 지연 시간을 비교한다. 현재 모델 선택은 그 결과에 따라 교체할 수 있도록 OCR 호출부를 별도 모듈로 분리했다.
