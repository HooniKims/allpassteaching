# SAMR 에듀테크 설계

기술이 기존 과제를 단순히 대신하는지, 기능을 개선하는지, 과제를 크게 바꾸는지, 이전에는 어려웠던 수행을 가능하게 하는지 점검한다. 수업 화면에서는 이를 시간 순서형 모형이 아닌 과제 재설계의 점검 틀로 안내한다.

## 설계 점검 수준

아래 네 수준은 도입-전개-정리의 시간 순서가 아니다. 기술 활용으로 학습 과제가 어느 정도 달라지는지 점검하고, 수업 목표에 필요한 수준을 선택한다.

1. 대체(Substitution): 기능 변화 없이 기존 도구를 디지털 기술로 대신한다.
2. 증강(Augmentation): 기존 과제의 틀을 유지하면서 유용한 기능 개선을 더한다.
3. 수정(Modification): 기술을 활용해 과제의 협업·피드백·표현 방식을 의미 있게 다시 설계한다.
4. 재정의(Redefinition): 기술 없이는 어려웠던 새로운 수행을 가능하게 한다.

## 피해야 할 흐름

재정의를 무조건 목표로 삼지 말고 학습 목표와 학생의 접근성에 맞는 수준을 선택한다.
