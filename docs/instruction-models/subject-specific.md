# 교과별 특화 모형
## 적용 목적
반응 중심, 실천적 문제 해결, 수학적 모델링 등 교과 고유의 탐구·표현 관습이 필요할 때 사용한다.
## 단계별 교사 행동
교과 맥락·핵심 개념 확인, 고유 자료·도구 코칭, 교과 표현 적용, 기준 기반 성찰을 돕는다.
## 단계별 학생 행동과 증거
핵심 질문, 교과 고유 탐구 기록, 교과 언어·기호·작품·수행, 자기 점검이 필요하다.
## 피해야 할 적용
과목 이름만 바꾸고 모든 교과에 같은 일반 활동을 적용하지 않는다.
