# 프로젝트 학습
## 적용 목적
여러 차시에 걸쳐 실제적 주제를 탐구하고 의미 있는 산출물을 만들 때 사용한다.
## 단계별 교사 행동
주제·산출물 기준, 역할·일정 계획, 중간 점검, 공유와 성찰을 구조화한다.
## 단계별 학생 행동과 증거
주제 선택 근거, 프로젝트 계획표, 진행 기록과 수정본, 최종 공유·성찰이 필요하다.
## 피해야 할 적용
예쁜 결과물 제작만 남고 성취기준과 탐구 과정이 사라지지 않게 한다.
