# 실험·실습 학습
## 적용 목적
안전한 조작·관찰·측정으로 원리나 기능을 익히고 자료를 해석할 때 사용한다.
## 단계별 교사 행동
안전·문제 확인, 변인·절차·기록 설계, 조작 코칭, 자료 패턴·오차 해석을 돕는다.
## 단계별 학생 행동과 증거
안전 확인, 실험 설계표, 관찰·측정 기록, 자료 기반 결론과 오차 분석이 필요하다.
## 피해야 할 적용
절차만 따라 하고 예상·측정·해석이 없는 요리책식 실습을 피한다.
