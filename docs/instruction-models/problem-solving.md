# 문제 해결 학습
## 적용 목적
열린 실제 문제를 정의하고 필요한 지식을 찾아 해결안을 실행·평가할 때 사용한다.
## 단계별 교사 행동
조건·목표 명료화, 필요 지식과 계획 수립, 전략 비교, 효과와 전이 평가를 돕는다.
## 단계별 학생 행동과 증거
문제 정의문, 해결 계획, 실행 기록, 해결안 평가와 개선점이 남아야 한다.
## 피해야 할 적용
정답과 절차가 정해진 연습문제를 열린 문제로 포장하지 않는다.
