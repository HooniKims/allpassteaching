# 융합수업

두 개 이상 교과의 개념, 방법, 표현 방식을 공통 맥락과 문제 안에서 연결한다. 교과 활동을 나열하는 데 그치지 않고, 각 관점이 문제를 설명하거나 해결하는 데 어떻게 기여하는지 학생의 통합 산출물과 성찰로 확인한다.

## 적용 흐름

1. 공통 맥락·문제
2. 교과 관점 탐구
3. 관점 통합
4. 적용·성찰

## 피해야 할 흐름

교과 이름만 여러 개 붙이고 실제 개념·방법의 연결이 없는 나열식 활동은 피한다.
