# 직접 교수
## 적용 목적
명확한 기능과 절차를 정확하게 익히고 점차 교사의 도움을 줄일 때 사용한다.
## 단계별 교사 행동
목표·절차 설명, 사고 과정 시범, 단서와 즉각 피드백, 독립 수행 확인 순으로 설계한다.
## 단계별 학생 행동과 증거
절차 재진술, 시범 관찰 기록, 안내된 수행 수정, 독립 수행 결과가 보여야 한다.
## 피해야 할 적용
설명만 이어지고 학생 연습과 피드백이 없는 수업을 피한다.
