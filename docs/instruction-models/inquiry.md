# 탐구·발견 학습
## 적용 목적
현상에서 질문을 만들고 가설을 증거로 검토해 설명을 구성할 때 사용한다.
## 단계별 교사 행동
탐구 문제 도출, 검증 가능한 가설, 자료 수집·해석, 증거 기반 결론을 코칭한다.
## 단계별 학생 행동과 증거
탐구 질문, 가설과 근거, 관찰·측정 기록, 증거 기반 결론이 보여야 한다.
## 피해야 할 적용
교사가 결론을 먼저 설명하고 학생이 확인 활동만 하는 흐름을 피한다.
