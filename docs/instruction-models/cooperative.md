# 협동 학습
## 적용 목적
공동 목표와 개인 책무를 함께 두고 서로 설명·도움·피드백하며 학습할 때 사용한다.
## 단계별 교사 행동
공동 과제와 성공 기준, 역할 책임, 참여 균형 코칭, 자기·동료 평가를 설계한다.
## 단계별 학생 행동과 증거
역할 계획, 개인 기여, 공동 산출물, 자기·동료 평가 근거가 보여야 한다.
## 피해야 할 적용
한 학생이 대부분 수행하고 나머지는 결과만 공유하는 무임승차 구조를 피한다.
