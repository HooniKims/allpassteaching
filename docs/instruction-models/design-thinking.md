# 디자인 씽킹
## 적용 목적
사용자 필요를 이해하고 문제를 재정의해 아이디어를 빠르게 시제품으로 시험할 때 사용한다.
## 단계별 교사 행동
사용자 관찰·질문, 필요 기반 문제 정의, 아이디어 확장, 시제품·피드백 반복을 촉진한다.
## 단계별 학생 행동과 증거
공감 기록, 문제 정의문, 아이디어 시각화, 시제품과 사용자 피드백 반영이 필요하다.
## 피해야 할 적용
사용자 공감 없이 교사가 정한 문제의 장식적 결과물만 만들지 않는다.
