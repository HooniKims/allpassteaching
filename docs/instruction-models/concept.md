# 개념 학습
## 적용 목적
정례와 비례를 비교해 결정적 속성을 찾고 개념을 새 사례에 적용할 때 사용한다.
## 단계별 교사 행동
대조 사례 제시, 속성 비교 질문, 개념어 정교화, 새 사례 판단을 돕는다.
## 단계별 학생 행동과 증거
사례 분류표, 속성 목록, 근거 있는 개념 정의, 새 사례 판단이 남아야 한다.
## 피해야 할 적용
정의를 먼저 암기시킨 뒤 같은 예만 반복하지 않는다.
