# TPACK 수업 설계

가르칠 내용 지식, 학생이 배우는 데 적합한 교수법, 학습을 돕는 기술 지식을 학급 맥락에 맞게 함께 설계한다. 특정 도구를 먼저 정하지 않고 성취기준과 학습 증거에서 출발해 기술의 교육적 이점, 접근성, 개인정보, 대체 수단을 점검한다.

## 설계 점검 기준

아래 기준은 도입-전개-정리의 시간 순서가 아니다. 한 차시 전체에서 내용·교수법·기술·학급 맥락이 서로 맞는지 순서와 무관하게 확인한다.

1. 내용·목표 확인
2. 교수법 선택
3. 기술 적합성 검토
4. 통합·맥락 점검

## 피해야 할 흐름

도구를 먼저 정한 뒤 학습 목표와 교수법을 끼워 맞추는 설계는 피한다.
