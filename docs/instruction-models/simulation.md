# 역할놀이·시뮬레이션
## 적용 목적
실제와 유사한 상황에서 역할과 관점을 경험하고 의사결정·소통을 연습할 때 사용한다.
## 단계별 교사 행동
상황·역할·규칙·안전 안내, 역할 준비 지원, 실행 관찰, 역할 밖 디브리핑을 실시한다.
## 단계별 학생 행동과 증거
역할 분석, 행동 계획, 상황 속 상호작용, 판단 이유와 관점 변화 성찰이 보여야 한다.
## 피해야 할 적용
재미있는 연기에 머물고 학습 목표와 디브리핑이 없는 흐름을 피한다.
