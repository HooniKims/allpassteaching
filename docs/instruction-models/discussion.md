# 토의·토론 학습
## 적용 목적
여러 관점이 가능한 쟁점을 근거로 비교하고 합의점과 차이점을 정리할 때 사용한다.
## 단계별 교사 행동
쟁점·대화 규칙, 근거 출처 점검, 반론 촉진, 입장 변화와 남은 쟁점 정리를 돕는다.
## 단계별 학생 행동과 증거
잠정 입장, 주장·반대 근거, 경청·질문·반론 기록, 논의 결과가 필요하다.
## 피해야 할 적용
근거 없이 찬반 의견만 말하거나 교사가 결론을 대신 정하지 않는다.
