# 거꾸로·블렌디드 학습
## 적용 목적
사전 학습과 교실의 고차적 적용·협력 활동을 명확하게 연결할 때 사용한다.
## 단계별 교사 행동
접근 가능한 사전 자료, 준비 확인, 교실 적용 활동, 즉각 피드백과 후속 학습을 설계한다.
## 단계별 학생 행동과 증거
사전 학습 기록·질문, 확인 응답, 적용·협력 산출물, 피드백 반영이 보여야 한다.
## 피해야 할 적용
사전 영상을 확인하고 교실에서 같은 내용을 다시 강의하지 않는다.
